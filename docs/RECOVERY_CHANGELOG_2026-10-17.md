# Firefly 恢复模块（2026-10-17）

这是对上游完整 Firefly 6.16.8 工程的**叠加恢复**，绝不替换完整主题。`cloud-functions/` 与 `src/server/` 是保留修订号的 CMS 后端；`/admin/` 提供登录与文章、动态、相册目录、设置管理。读取历史公开内容与展示旧站 UI 不需要启用写入。***EdgeOne Blob 的跨实例原子写入尚未确认，禁止在未经验证时开启写入***。`FIREFLY_ENABLE_WRITES` 默认禁用。

原站公开文章与动态使用源站 2026-10-17 HTTP 200 的公开记录重建，避免上游 Demo 替代私人内容。部分非公开资料、旧 Git 历史、全部图片上传能力仍没有拿到完整源码。

上线前由用户在 EdgeOne 预览域名逐项检查后台登录/会话、隐私、动态、搜索、图库与图床，生产密码和密钥仅设为 EdgeOne 环境变量，不写入 GitHub。
